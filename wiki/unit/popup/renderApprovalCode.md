# renderApprovalCode

승인 대기 화면에 코드와 복사 버튼을 표시합니다.

## 시그니처

```typescript
export function renderApprovalCode(code: string): HTMLElement;
```

| 매개변수 | 타입     | 기본값 | 의미                                                                 |
| -------- | -------- | ------ | -------------------------------------------------------------------- |
| code     | `string` | 없음   | 확장에서 받은 승인 코드입니다. 화면에는 받은 값을 그대로 표시합니다. |

| 반환        | 의미                                                 |
| ----------- | ---------------------------------------------------- |
| HTMLElement | 제목, 코드, 사용 안내와 복사 버튼을 담은 영역입니다. |

## 내부 로직

1. 승인 대기 제목과 입력 코드를 순서대로 넣습니다.
2. MCP 클라이언트에 승인을 요청하는 안내를 표시합니다.
3. 코드 복사 보조 버튼을 마지막에 넣습니다.

## 사용법

```typescript
const panel = renderApprovalCode("ABCD-1234-5678");
```
