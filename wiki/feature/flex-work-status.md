# 본인 근무 상태

승인한 Chrome 연결에서 본인의 현재 근무 기록 상태를 조회합니다. 승인한 팝업 시안은 [이슈 코멘트](https://github.com/freevue/flex-mcp/issues/26#issuecomment-6717236892)에 있습니다.

## 구성 유닛

| 유닛                                                              | 역할                                                |
| ----------------------------------------------------------------- | --------------------------------------------------- |
| [registerPairedReadTools](../unit/mcp/registerPairedReadTools.md) | 연결 키를 받는 근무 상태 도구를 등록합니다.         |
| [readLiveReply](../unit/bridge/readLiveReply.md)                  | 승인된 확장에서 현재 근무 상태를 읽어 응답합니다.   |
| [isWorkStatusResult](../unit/shared/isWorkStatusResult.md)        | 요청에 대응하는 상태 응답의 모양과 값을 검사합니다. |

## 흐름

| 순서 | 이벤트             | 입력과 식별자                     | 성공 결과                                   | 실패·취소 결과                                                 | 담당 유닛                 |
| ---- | ------------------ | --------------------------------- | ------------------------------------------- | -------------------------------------------------------------- | ------------------------- |
| 1    | MCP 도구 호출      | 기존 승인 연결 키                 | 승인한 채널에 근무 상태 요청을 보냅니다.    | 미승인과 미연결은 기존 오류를 반환합니다.                      | `registerPairedReadTools` |
| 2    | 확장에서 조회      | 요청 ID, 확장에 연결된 계정       | 조회 시점의 상태만 응답합니다.              | 상태를 읽을 수 없으면 미확인 또는 기존 접근 오류를 반환합니다. | `readLiveReply`           |
| 3    | 서버에서 응답 확인 | 요청 ID, 대기 중인 근무 상태 요청 | 고정 상태 값과 합성 결과 표시만 전달합니다. | 다른 요청의 결과, 여분 필드와 알 수 없는 값은 거부합니다.      | `isWorkStatusResult`      |

`flex_get_work_status`는 승인한 연결 키만 받습니다. 계정과 기간은 받지 않습니다. 기존 요청 제한과 연결 해제를 따릅니다. 읽기 도구이며 근무 및 휴게 기록을 변경하지 않습니다.

[근무 상태 결과](../type/shared/WorkStatusResult.md)의 네 값만 반환합니다. 합성 연결은 `working`과 `synthetic: true`를 반환합니다. 브라우저의 로그인 값, 기록 원본과 내부 식별자는 전달하지 않습니다.

공식 Open API는 진행 중인 근무와 휴게를 지원합니다. 이용 권한이 확인되지 않은 회사용 토큰을 사용하지 않습니다. 개인 설치본은 승인된 Flex 화면이 사용하는 본인 기록을 읽습니다. 상태를 알 수 없는 응답은 진행 기록 없음으로 바꾸지 않습니다.
