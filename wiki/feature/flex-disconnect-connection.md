# 내 MCP 연결 해제

사용자가 해제를 요청하면 MCP 클라이언트는 현재 사용 중인 연결 키를 폐기합니다. Chrome 소켓 하나를 여러 MCP 클라이언트가 공유할 수 있습니다.

## 구성 유닛

| 유닛                                                              | 역할                                                               |
| ----------------------------------------------------------------- | ------------------------------------------------------------------ |
| [disconnectMcpConnection](../unit/mcp/disconnectMcpConnection.md) | 요청한 연결 키를 폐기하고 마지막 키일 때 Chrome 등록을 해제합니다. |

## 흐름

| 순서 | 입력                                                       | 성공 결과                                                                                                        | 실패 결과                                                                   |
| ---- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 1    | `flex_disconnect_connection`에 `connectionKey`만 보냅니다. | 현재 승인한 키의 소유자와 Chrome 등록을 확인합니다.                                                              | 입력 형식이 다르면 거부합니다. 없는 키나 폐기한 키는 `ACCESS_DENIED`입니다. |
| 2    | 서버가 확인한 연결입니다.                                  | 연결 키와 해당 키로 대기 중인 조회를 폐기합니다.                                                                 | 확인할 수 없는 연결은 바꾸지 않습니다.                                      |
| 3    | 같은 Chrome 등록에 남은 키를 확인합니다.                   | 키가 남으면 등록과 소켓을 유지합니다. 마지막 키면 등록, 대기 코드와 접속권을 폐기하고 열려 있는 소켓을 닫습니다. | 저장소 오류는 해제 실패로 반환합니다.                                       |

원격 Node와 Workers만 이 도구를 제공합니다. 도구는 상태를 바꾸므로 사용자에게 해제 요청을 받은 경우에 호출합니다. 사용한 키는 응답이나 대화에 표시하지 않습니다.

성공 시 `status: "disconnected"`를 반환합니다. `chromeRegistration: "preserved"`는 다른 MCP 키가 남아 있다는 뜻입니다. `chromeRegistration: "removed"`는 마지막 키와 Chrome 등록이 해제됐다는 뜻입니다. 해제한 MCP로 다시 조회하려면 갈피의 새 일회용 코드를 승인합니다.

## 관련 정책

| 정책                                                    | 적용 범위                                        |
| ------------------------------------------------------- | ------------------------------------------------ |
| [채널 접근 권한](../../docs/features/access-control.md) | 현재 연결 키와 그 키의 Chrome 등록만 변경합니다. |
