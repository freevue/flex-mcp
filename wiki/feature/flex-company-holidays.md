# 내 회사 휴일

`flex_get_company_holidays`는 한국 시간의 시작일과 종료일을 모두 받습니다. 두 날짜를 포함해 최대 31일을 읽습니다. 승인한 연결 키만 허용하며 계정이나 휴일 그룹은 입력받지 않습니다.

## 구성 유닛

| 유닛                                                              | 역할                                               |
| ----------------------------------------------------------------- | -------------------------------------------------- |
| [registerPairedReadTools](../unit/mcp/registerPairedReadTools.md) | 연결 키와 기간 입력을 검사합니다.                  |
| [readLiveReply](../unit/bridge/readLiveReply.md)                  | 승인된 계정의 범위를 확인하는 어댑터에 요청합니다. |
| [isCompanyHolidays](../unit/shared/isCompanyHolidays.md)          | 결과의 기간, 휴일 필드와 순서를 확인합니다.        |
| [isWorkStatusResult](../unit/shared/isWorkStatusResult.md)        | 기존 근무 상태의 응답을 검사합니다.                |

## 흐름

| 순서 | 이벤트        | 입력과 식별자               | 성공 결과                                                          | 실패·취소 결과                                                 | 담당 유닛                 |
| ---- | ------------- | --------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------- | ------------------------- |
| 1    | 도구 호출     | 연결 키와 날짜 두 개        | 승인한 채널에 조회를 보냅니다.                                     | 기간과 연결 오류를 반환합니다.                                 | `registerPairedReadTools` |
| 2    | 브라우저 조회 | 등록한 계정, 기간과 요청 ID | 본인에게 적용되는 휴일만 읽습니다.                                 | 적용 그룹 또는 유형을 확인할 수 없으면 조회 불가를 반환합니다. | `readLiveReply`           |
| 3    | 응답 확인     | 요청 ID와 원래 기간         | [휴일 결과](../type/shared/CompanyHolidaysResult.md)만 반환합니다. | 추가 필드와 범위 밖의 휴일은 거부합니다.                       | `isCompanyHolidays`       |

[Flex 공식 휴일 API](https://developers.flex.team/reference/getholidays)는 그룹별로 공휴일과 회사 자체 휴일을 구분합니다. 연결한 계정에서 관찰한 웹 응답은 두 유형을 구분하지 않았습니다. 공식 API 접근과 본인 그룹을 확인하기 전에는 실조회 어댑터를 연결하지 않습니다. 휴일 이름과 요일로 유형을 추정하지 않습니다.

조회가 성공하고 휴일이 없으면 빈 목록을 반환합니다. 적용 그룹을 모르면 `FLEX_SCOPE_UNAVAILABLE`을 반환합니다. 근무 요약의 놀수 계산은 바뀌지 않습니다.
