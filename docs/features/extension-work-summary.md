# 확장 팝업의 이번 달 근무 요약

[팝업 구성 계획](extension-ui-plan.md) · [근무 시간 조회](work-hours.md) · [실조회 범위](reading-boundary.md) · [예정 연차 투두](https://github.com/freevue/flex-mcp/issues/18)

팝업은 MCP 소켓과 Flex 상태를 따로 표시합니다. 두 연결이 활성화된 경우에만 근무 요약을 표시합니다. 어느 하나가 비활성이면 근무 수치를 표시하지 않습니다. 개인 설치본은 등록한 계정의 Flex 탭에서 근무 자료를 읽습니다. 합성 모드에서는 예시임을 표시합니다.

## 표시할 값

날짜는 한국 시간으로 계산합니다. 누적은 이번 달 1일부터 오늘까지입니다. 남은 시간의 목표 기간은 이번 달 전체입니다.

| 표시                            | 기준                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------- |
| 오늘 실제 근무                  | 확정 집계에 아직 진행 중인 오늘의 실제 근무를 더합니다. 휴게 시간은 제외합니다. |
| 이번 달 인정 근무 · 연차 포함   | 오늘까지 인정된 근무에 앞으로 인정될 예정 연차 시간을 더합니다.                 |
| 이번 달 인정 근무 · 연차 미포함 | 오늘까지 인정된 근무입니다. 앞으로 인정될 예정 연차 시간을 더하지 않습니다.     |
| 이번 달 남은 시간 · 놀수 미반영 | 이번 달 기본 목표에서 오늘까지 인정된 근무와 앞으로 인정될 연차 시간을 뺍니다.  |
| 이번 달 남은 시간 · 놀수 반영   | 놀수를 적용한 목표에서 같은 인정 시간을 뺍니다.                                 |

두 인정 근무 값에 이미 인정된 사용 연차가 들어 있습니다. 새로 더하는 값은 예정 연차 중 인정될 시간뿐입니다. 예정 연차 인정분이 확인되지 않으면 연차 포함 합계와 남은 시간은 `계산 정보 없음`입니다. 오늘 실제 근무와 연차 미포함 합계는 그대로 표시합니다.

본인 조회용 팝업은 기존 15초 주기에 오늘 값을 갱신합니다. 진행 시간을 확인할 수 없거나 집계 중 기록이 바뀌면 오늘 값만 계산 정보 없음으로 표시합니다. 정상적인 0분과 구분합니다.

[상세 MCP 도구](../mcp/tools/flex-get-work-summary.md)는 이번 달 실제 누적, 사용·예정 연차와 인정분, 오늘 기준 및 예상 남은 시간을 반환합니다. 실제 근무와 인정 근무는 서로 다른 집계입니다.

## 휴무 적용

기본 목표는 승인한 자료에서 얻은 이번 달 전체 소정 근무 시간입니다. 휴무 차감분은 지정한 휴무 날짜 중 기본 목표에 포함된 소정 근무 시간입니다. 일부 수요일만 쉬는 규칙은 실제 날짜를 지정합니다. 같은 요일의 다른 날짜는 빼지 않습니다. 이미 휴무로 빠진 날짜는 다시 빼지 않습니다. 날짜별 목표를 알 수 없으면 임의로 8시간을 빼지 않습니다.

```text
휴무 미반영 = max(0, 이번 달 기본 목표 - 이번 달 인정 근무 누적)
휴무 반영 목표 = max(0, 이번 달 기본 목표 - 휴무 차감분)
휴무 반영 = max(0, 휴무 반영 목표 - 이번 달 인정 근무 누적)
예상 휴무 미반영 = max(0, 휴무 미반영 - 예정 연차 인정 시간)
예상 휴무 반영 = max(0, 휴무 반영 - 예정 연차 인정 시간)
```

기본 목표가 없으면 오늘 기준과 예상 남은 시간을 모두 계산하지 않습니다. 놀수 차감분만 알 수 없으면 놀수 미반영 값은 계산합니다. 놀수 반영 값에는 `계산 정보 없음`을 표시합니다. 휴무가 없다고 확인했거나 모두 이미 빠진 경우에는 두 값이 같습니다. 휴무 설정이 없는 달은 휴무가 없다고 가정하지 않습니다.

합성 모드에서는 수요일을 휴무로 설정한 예시를 사용합니다. 첫 두 수요일은 기본 목표에 각각 480분을 포함합니다. 그 외 수요일은 이미 휴무로 처리합니다. 개인 설치본은 확인한 놀수 날짜만 사용합니다. 월을 구간으로 나누어 각 구간의 소정 근무 시간을 읽습니다. 그 합이 월 전체 목표와 같을 때만 놀수 날짜의 시간을 뺍니다. 설정이 없는 달에는 놀수 반영 값을 표시하지 않습니다.

## 확인할 경우

| TC               | 조건                                                     | 기대 결과                                                                        |
| ---------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| TC-F-EXT-WORK-01 | MCP 연결됨, Flex 미연결                                  | 상태만 표시합니다. 근무 수치를 표시하지 않습니다.                                |
| TC-F-EXT-WORK-02 | 두 연결이 활성이고 자료를 읽습니다.                      | 오늘 실제 근무, 월 인정 근무, 놀수 전후 남은 시간을 표시합니다.                  |
| TC-F-EXT-WORK-03 | 기본 목표 160시간, 인정 누적 90시간, 휴무 차감 16시간    | 미반영 70시간, 반영 54시간을 표시합니다.                                         |
| TC-F-EXT-WORK-04 | 휴무일이 이미 월 목표에서 빠졌습니다.                    | 같은 휴무를 다시 빼지 않습니다.                                                  |
| TC-F-EXT-WORK-05 | 휴무일별 목표 시간이 없습니다.                           | 휴무 반영 값을 계산하지 않습니다.                                                |
| TC-F-EXT-WORK-06 | 인정 시간이 목표에 도달합니다.                           | 남은 시간은 0시간입니다.                                                         |
| TC-F-EXT-WORK-07 | 한 달에서 같은 요일 두 날짜만 휴무로 지정합니다.         | 지정한 두 날짜의 목표만 차감합니다. 같은 요일의 다른 날짜에는 적용하지 않습니다. |
| TC-F-EXT-WORK-08 | 오늘 기준 70시간과 54시간, 예정 연차 8시간 중 6시간 인정 | 팝업은 64시간과 48시간을 표시합니다. MCP는 오늘 기준도 반환합니다.               |
| TC-F-EXT-WORK-09 | 예정 연차의 인정 시간을 알 수 없습니다.                  | 연차 미포함 값은 유지합니다. 연차 포함 값과 남은 시간은 계산 정보 없음입니다.    |

팝업을 열면 Chrome에서 조회합니다. 팝업을 열어 둔 동안 15초마다 다시 조회합니다. 읽기 전후의 계정과 탭이 같은지 확인합니다. 팝업을 열 때 계산한 값은 서버로 보내지 않습니다. MCP가 유효한 연결 키로 상세 요약을 요청한 경우에만 확장이 같은 계산 결과를 중계합니다. 승인 코드, 로그와 연결 진단에도 넣지 않습니다.
