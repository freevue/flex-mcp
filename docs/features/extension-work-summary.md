# 확장 팝업의 이번 달 근무 요약

[팝업 구성 계획](extension-ui-plan.md) · [근무 시간 조회](work-hours.md) · [실조회 범위](reading-boundary.md)

팝업은 MCP 소켓과 Flex 상태를 따로 표시합니다. 두 연결이 활성화된 경우에만 근무 요약을 표시합니다. 어느 하나가 비활성이면 근무 수치를 표시하지 않습니다. 현재 빌드에서는 합성 모드를 켜면 합성 근무 요약을 표시합니다. 실제 Flex 근무 자료는 연결하지 않았습니다.

## 표시할 값

날짜는 한국 시간으로 계산합니다. 누적은 이번 달 1일부터 오늘까지입니다. 남은 시간의 목표 기간은 이번 달 전체입니다.

| 표시 | 기준 |
| --- | --- |
| 오늘 근무 | 오늘의 실제 근무 시간 |
| 이번 달 누적 | 이번 달 1일부터 오늘까지의 실제 근무 시간 |
| 남은 시간 · 휴무 미반영 | 이번 달 기본 목표에서 이번 달 인정 근무 누적을 뺀 값 |
| 남은 시간 · 휴무 반영 | 휴무를 적용한 이번 달 목표에서 같은 인정 근무 누적을 뺀 값 |

실제 근무와 인정 근무는 별도 집계입니다. 실제 근무는 오늘과 누적 표시에 사용합니다. 남은 시간은 같은 인정 근무 값으로 계산합니다. 분 단위로 계산한 뒤 시와 분으로 표시합니다.

## 휴무 적용

기본 목표는 승인한 자료에서 얻은 이번 달 전체 소정 근무 시간입니다. 휴무 차감분은 지정한 휴무 날짜 중 기본 목표에 포함된 소정 근무 시간입니다. 일부 수요일만 쉬는 규칙은 실제 날짜를 지정합니다. 같은 요일의 다른 날짜는 빼지 않습니다. 이미 휴무로 빠진 날짜는 다시 빼지 않습니다. 날짜별 목표를 알 수 없으면 임의로 8시간을 빼지 않습니다.

```text
휴무 미반영 = max(0, 이번 달 기본 목표 - 이번 달 인정 근무 누적)
휴무 반영 목표 = max(0, 이번 달 기본 목표 - 휴무 차감분)
휴무 반영 = max(0, 휴무 반영 목표 - 이번 달 인정 근무 누적)
```

기본 목표가 없으면 두 남은 시간을 계산하지 않습니다. 휴무 차감분만 알 수 없으면, 휴무 미반영 값은 표시할 수 있습니다. 휴무 반영 값에는 `계산 정보 없음`을 표시합니다. 휴무가 없다고 확인했거나 모두 이미 빠진 경우에는 두 값이 같습니다. 휴무 설정이 없는 달은 휴무가 없다고 가정하지 않습니다.

합성 모드에서는 수요일을 휴무로 설정한 예시를 사용합니다. 첫 두 수요일은 기본 목표에 각각 480분을 포함합니다. 그 외 수요일은 이미 휴무로 처리합니다. 실제 휴무 요일과 날짜별 목표는 승인된 자료에서 받아야 합니다.

## 확인할 경우

| TC | 조건 | 기대 결과 |
| --- | --- | --- |
| TC-F-EXT-WORK-01 | MCP 연결됨, Flex 미연결 | 상태만 표시합니다. 근무 수치를 표시하지 않습니다. |
| TC-F-EXT-WORK-02 | 두 연결이 활성이고 자료를 읽습니다. | 오늘과 이번 달 누적, 휴무 반영 전·후를 표시합니다. |
| TC-F-EXT-WORK-03 | 기본 목표 160시간, 인정 누적 90시간, 휴무 차감 16시간 | 미반영 70시간, 반영 54시간을 표시합니다. |
| TC-F-EXT-WORK-04 | 휴무일이 이미 월 목표에서 빠졌습니다. | 같은 휴무를 다시 빼지 않습니다. |
| TC-F-EXT-WORK-05 | 휴무일별 목표 시간이 없습니다. | 휴무 반영 값을 계산하지 않습니다. |
| TC-F-EXT-WORK-06 | 인정 시간이 목표에 도달합니다. | 남은 시간은 0시간입니다. |
| TC-F-EXT-WORK-07 | 한 달에서 같은 요일 두 날짜만 휴무로 지정합니다. | 지정한 두 날짜의 목표만 차감합니다. 같은 요일의 다른 날짜에는 적용하지 않습니다. |

근무 결과는 해당 팝업에만 표시합니다. 승인 코드, 로그와 연결 진단에는 넣지 않습니다. 실제 자료는 [투두 7](https://github.com/freevue/flex-mcp/issues/7)의 승인을 받은 뒤 확인합니다.
