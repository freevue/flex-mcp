갈피 개인정보 처리방침

이 방침은 Chrome 웹 스토어에서 지정한 테스터에게 배포하는 갈피에 적용합니다. 갈피는 Chrome에서 로그인한 본인의 Flex 정보를 사용자가 승인한 MCP 클라이언트에서 조회할 수 있게 합니다. MCP 클라이언트는 갈피에 조회를 요청할 수 있는 AI 도구입니다. 갈피에 별도로 가입하거나 Flex 비밀번호를 입력할 필요는 없습니다.

어떤 정보를 읽나요?

갈피는 본인의 연차 잔액, 실제·인정 근무 시간과 현재 근무 기록 상태, 기본 캘린더에 있는 미팅의 날짜와 시간대를 읽습니다. 미팅 제목과 참석자 정보는 전달하지 않습니다. 다른 구성원 프로필과 팀 일정은 조회하지 않습니다.

Flex 계정이 연결할 때와 같은지 확인하는 데 필요한 식별값은 Chrome 안에서 처리합니다. 계정 비교용 해시는 Chrome에 저장합니다. Flex 비밀번호, 세션 쿠키, 인증 토큰과 계정 비교용 해시는 갈피 서버나 MCP 클라이언트에 보내지 않습니다.

어디로 보내고 무엇을 보관하나요?

승인한 MCP 클라이언트가 조회를 요청하면 갈피는 필요한 결과를 암호화된 연결로 Cloudflare Workers에서 운영하는 갈피 서버를 거쳐 해당 클라이언트에 전달합니다. 갈피 서버는 조회 결과를 데이터베이스나 애플리케이션 로그에 기록하지 않습니다. 클라이언트의 대화 기록에 결과가 남을 수 있으며, 보관과 삭제는 해당 서비스의 정책과 설정에 따릅니다.

Chrome에는 확장 연결 정보가 남습니다. 갈피 서버는 연결 등록에 필요한 식별자와 연결 키의 해시를 보관합니다. 등록 정보는 연결을 해제하거나 교체할 때까지 유효할 수 있습니다. 승인 코드는 5분 뒤 만료됩니다. 서버는 요청이 몰리는 것을 막기 위해 접속 IP에서 시간 구간별 제한값을 계산합니다.

갈피의 배포 구성은 처리 국가를 지정하지 않습니다. 정보는 해외에서 처리될 수 있으며, 실제 처리 위치는 Cloudflare 인프라와 설정에 따라 달라집니다.

어떻게 사용을 중지하거나 삭제를 요청하나요?

Chrome에서 갈피를 사용 중지하거나 제거하면 새 조회 결과를 보내지 않습니다. 서버 연결 해제, 보관 정보의 열람·정정·삭제, 동의 철회는 아래 이메일로 요청할 수 있습니다. 이미 MCP 클라이언트의 대화에 저장된 결과는 해당 클라이언트에서 관리합니다.

갈피는 사용자 데이터를 본인 조회, 연결 관리와 서비스 보호에 사용합니다. 데이터를 판매하거나 광고에 이용하지 않습니다. 갈피의 사용자 데이터 사용은 Chrome 웹 스토어의 제한적 사용 요건을 따릅니다.
