# copyPendingCode

[유틸 목록](../../UTILITIES.md) · [상태 화면](../screens/status.md)

사용자가 버튼을 누르면 코드를 클립보드에 쓸 준비를 합니다. 발급이 끝나면 코드만 복사합니다. 구현은 `apps/chrome-extension/src/popup.ts`에 있습니다.

```typescript
declare function copyPendingCode(
  pending: Promise<string | null>,
): Promise<boolean>;
```

| 매개변수  | 설명                                                                  |
| --------- | --------------------------------------------------------------------- |
| `pending` | 승인 코드가 준비되면 문자열을 반환합니다. 코드가 없으면 `null`입니다. |

| TC                        | 조건                                        | 기대 결과                                                        |
| ------------------------- | ------------------------------------------- | ---------------------------------------------------------------- |
| TC-U-COPY-PENDING-CODE-01 | 코드 확인을 누르고 유효한 코드를 받습니다.  | 코드만 복사하고 `true`를 반환합니다.                             |
| TC-U-COPY-PENDING-CODE-02 | 코드가 없거나 브라우저가 복사를 거부합니다. | `false`를 반환합니다. 코드가 있으면 화면에서 선택할 수 있습니다. |
