# 팝업 버튼

[공용 컴포넌트](README.md)

`popupButton(label, action, secondary?)`는 팝업 버튼을 만듭니다. 클릭 동작은 팝업이 처리합니다.

| 매개변수 | 타입 | 설명 |
| --- | --- | --- |
| `label` | `string` | 사용자가 읽는 버튼 이름입니다. |
| `action` | `PopupCommand \| "copy"` | 팝업이 실행할 동작입니다. |
| `secondary` | `boolean` | 선택입니다. `true`이면 보조 버튼을 표시합니다. |

확인할 경우: 키보드로 각 버튼을 선택할 수 있습니다. 선택한 버튼의 표시가 보입니다.
