# 승인 코드 영역

[연결 화면](../screens/connection.md)

`renderApprovalCode(code)`는 승인 대기 화면의 코드와 복사 버튼을 만듭니다. `code`는 서버가 사용자에게 보여주도록 발급한 문자열입니다. 요청 키는 받지 않습니다.

코드는 고정폭 글꼴과 보라색을 사용합니다. 복사 버튼은 팝업이 처리합니다. 코드가 만료되면 영역을 지웁니다.

| TC | 조건 | 기대 결과 |
| --- | --- | --- |
| TC-UI-APPROVAL-CODE-01 | 팝업에서 코드를 발급합니다. | 코드와 복사 버튼을 표시합니다. 요청 키는 표시하지 않습니다. |
| TC-UI-APPROVAL-CODE-02 | 복사 버튼을 누릅니다. | 사용자가 보는 코드만 복사합니다. |
