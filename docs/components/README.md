# 팝업 공용 컴포넌트

[디자인 기준](../../DESIGN.md) · [팝업 흐름](../features/extension-ui-plan.md)

컴포넌트는 팝업에 표시할 HTML 요소를 만듭니다. 네트워크 요청이나 Chrome 등록은 처리하지 않습니다.

| 컴포넌트 | 역할 |
| --- | --- |
| [팝업 버튼](popup-button.md) | 코드 발급, 복사, 재연결과 상태 확인에 사용합니다. |
| [승인 코드](approval-code.md) | 승인 대기 중 사용자가 보낼 코드를 표시합니다. |
| [연결 상태 행](connection-rows.md) | MCP와 Flex 상태를 따로 표시합니다. |
| [근무 요약](work-summary.md) | 오늘과 이번 달 근무 시간, 오늘 기준과 예정 연차 반영 예상치를 표시합니다. |
