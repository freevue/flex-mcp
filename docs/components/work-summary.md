# 근무 요약 영역

[근무 요약 화면](../screens/work-summary.md)

`renderWorkSummary(summary, source)`는 오늘 실제 근무, 이번 달 인정 근무와 놀수 전후 남은 시간을 순서대로 표시합니다. `summary: PopupWorkSummary`는 분 단위 요약입니다. `source: "live" | "synthetic"`는 실제와 예시를 구분합니다. 반환값은 `HTMLElement`입니다. 이 함수는 Flex에 접속하지 않습니다.

두 인정 합계 중 연차 포함에만 예정 연차 인정분을 더합니다. 남은 시간은 두 예상치를 사용합니다. 숫자는 폭이 일정한 글자를 사용합니다. 알 수 없는 값은 계산 정보 없음으로 표시합니다.

| TC                    | 조건                                  | 기대 결과                                                                        |
| --------------------- | ------------------------------------- | -------------------------------------------------------------------------------- |
| TC-UI-WORK-SUMMARY-01 | 승인된 확장에서 근무 요약을 읽습니다. | 오늘 실제 근무를 먼저 표시합니다. 월 인정 근무와 놀수 전후를 두 열로 표시합니다. |
| TC-UI-WORK-SUMMARY-02 | 놀수 반영 시간이 `null`입니다.        | 해당 값에 계산 정보 없음이라고 표시합니다.                                       |
