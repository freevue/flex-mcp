# 근무 요약 영역

[근무 요약 화면](../screens/work-summary.md)

`renderWorkSummary(summary)`는 실제 근무 두 값과 남은 시간 두 값을 표시합니다. `summary`는 분 단위의 계산 결과입니다. 값이 없으면 계산 정보가 없다고 표시합니다.

숫자는 폭이 일정한 글자를 사용합니다. 휴무 반영 전과 후를 같은 너비로 표시합니다. 이 컴포넌트는 Flex에 접속하지 않습니다.

| TC | 조건 | 기대 결과 |
| --- | --- | --- |
| TC-UI-WORK-SUMMARY-01 | 네 수치를 모두 전달합니다. | 오늘과 월 누적을 위에 표시합니다. 휴무 반영 전과 후를 아래에 표시합니다. |
| TC-UI-WORK-SUMMARY-02 | 휴무 반영 시간이 `null`입니다. | 해당 값에 계산 정보 없음이라고 표시합니다. |
