# 근무 요약 영역

[근무 요약 화면](../screens/work-summary.md)

`renderWorkSummary(summary, source)`는 실제 근무, 인정 합계, 사용·예정 연차와 남은 시간을 표시합니다. `summary`는 분 단위의 계산 결과입니다. `source`는 `live` 또는 `synthetic`입니다. 실제 값에는 Flex 기준, 합성 값에는 예시를 표시합니다. 남은 시간 표는 오늘 기준과 예정 연차 반영을 행으로 나눕니다. 각 행의 열은 놀수 미반영과 놀수 반영입니다. 값이 없으면 계산 정보가 없다고 표시합니다.

숫자는 폭이 일정한 글자를 사용합니다. 놀수 반영 전과 후를 같은 너비로 표시합니다. 이 컴포넌트는 Flex에 접속하지 않습니다.

| TC | 조건 | 기대 결과 |
| --- | --- | --- |
| TC-UI-WORK-SUMMARY-01 | 근무와 연차 집계를 전달합니다. | 오늘과 월 누적, 인정과 연차, 남은 시간 표 순으로 표시합니다. |
| TC-UI-WORK-SUMMARY-02 | 놀수 반영 시간이 `null`입니다. | 해당 값에 계산 정보 없음이라고 표시합니다. |
