# flex_get_work_status

[도구 목록](../README.md) · [근무 상태 명세](../../../wiki/feature/flex-work-status.md)

연결을 승인한 Chrome에서 본인의 현재 근무 기록 상태를 읽습니다. 원격 서버에서 승인한 `connectionKey`가 필요합니다. 계정이나 날짜를 지정할 수 없습니다.

| 결과       | 화면 문구    | 의미                                               |
| ---------- | ------------ | -------------------------------------------------- |
| `working`  | 근무 중      | 진행 중인 근무 기록이 있습니다.                    |
| `on_break` | 휴게 중      | 진행 중인 근무에 끝나지 않은 휴게 기록이 있습니다. |
| `idle`     | 기록 중 아님 | 진행 중인 기록이 없음을 확인했습니다.              |
| `unknown`  | 확인 불가    | 현재 기록 상태를 판정할 수 없습니다.               |

응답의 `status`는 위 표의 값 중 하나입니다. 공개 확장의 합성 연결은 `working`과 `synthetic: true`를 반환합니다. 계정이 바뀌거나 연결이 없으면 기존 접근 오류를 반환합니다. 이 도구는 기록을 변경하지 않습니다.
