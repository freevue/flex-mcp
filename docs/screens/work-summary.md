# 팝업 근무 요약 화면

[계산 정책](../features/extension-work-summary.md) · [근무 요약 컴포넌트](../components/work-summary.md)

근무 요약은 연결 상태 아래에 표시합니다. 오늘 실제 근무와 이번 달 실제 근무 누적을 먼저 표시합니다. 이번 달 인정 합계, 사용 연차와 그중 인정된 시간, 예정 연차를 따로 표시합니다. 그 아래 표에서 오늘 기준과 예정 연차 반영 예상치를 비교합니다. 표의 두 열은 놀수 미반영과 놀수 반영입니다.

자료가 없으면 알 수 없는 값을 0으로 바꾸지 않습니다. 합성 모드에서는 예시 수치임을 표시합니다. 화면에는 연결 키와 요청 키를 표시하지 않습니다.

| 확인할 경우 | 기대 결과 |
| --- | --- |
| 월 목표 160시간, 인정 누적 90시간과 휴무 차감 16시간을 받습니다. | 70시간과 54시간을 표시합니다. |
| 휴무 차감분을 알 수 없습니다. | 휴무 반영 값에 계산 정보가 없다고 표시합니다. |
| 예정 연차 중 6시간이 인정됩니다. | 예상치 두 값은 각각 6시간 줄어듭니다. 오늘 기준 값은 그대로입니다. |
| Flex 상태가 비활성으로 바뀝니다. | 근무 수치를 모두 숨깁니다. |
