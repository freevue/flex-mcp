# 갈피 근무 요약 화면

[bab Wiki 명세](../../wiki/feature/galpi-work-dashboard.md) · [계산 정책](../features/extension-work-summary.md) · [근무 요약 컴포넌트](../components/work-summary.md) · [상세 MCP 도구](../mcp/tools/flex-get-work-summary.md)

연결 상태 바로 아래에 오늘 실제 근무를 표시합니다. 이번 달 인정 근무에는 연차 포함과 미포함 합계를 나란히 표시합니다. 포함 값은 앞으로 인정될 예정 연차만 더합니다. 이미 인정된 사용 연차는 두 값에 들어 있습니다.

이번 달 남은 시간에는 예정 연차의 인정분을 반영합니다. 왼쪽에 놀수 반영, 오른쪽에 놀수 미반영을 표시합니다. 두 값은 배경 없이 나란히 둡니다. 실제 누적과 사용·예정 연차 상세는 MCP에서 읽습니다.

| 확인할 경우                                                                            | 기대 결과                                                                        |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 월 목표 160시간, 인정 누적 90시간, 예정 연차 인정 6시간과 놀수 차감 16시간을 받습니다. | 인정 근무는 96시간과 90시간입니다. 남은 시간은 왼쪽 48시간, 오른쪽 64시간입니다. |
| 놀수 차감분을 알 수 없습니다.                                                          | 놀수 반영 값에는 계산 정보 없음이라고 표시합니다.                                |
| Flex 상태가 비활성으로 바뀝니다.                                                       | 근무 수치를 모두 숨깁니다.                                                       |
