# 에이전트 대화의 연결 승인

[Chrome 등록](../features/browser-pairing.md) · [MCP 승인 함수](../utilities/approve-device-pairing.md)

사용자는 확장에 표시된 코드를 기존 에이전트 대화에 보냅니다. 사용자가 연결 승인을 요청하면, 에이전트는 `flex_approve_connection`을 호출합니다. 별도 서버 화면은 없습니다.

서버는 승인 권한이 있는 호출자의 계정에 요청을 묶습니다. 에이전트는 승인 결과만 받습니다. 승인 직후에 Chrome이 연결됐다고 안내하지 않습니다.

| 확인할 경우 | 기대 결과 |
| --- | --- |
| 승인 권한이 있는 에이전트가 유효한 코드를 보냅니다. | 승인 결과를 받습니다. 처음 요청한 확장만 등록을 받을 수 있습니다. |
| 조회 권한만 있는 에이전트가 같은 코드를 보냅니다. | 승인을 거부합니다. |
