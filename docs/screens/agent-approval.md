# MCP 클라이언트에서 연결 승인

[Chrome 등록과 재접속](../features/browser-pairing.md) · [승인 도구](../mcp/tools/flex-approve-connection.md)

사용자는 Chrome 팝업의 일회용 코드를 MCP 클라이언트에 전달합니다. 클라이언트가 `flex_approve_connection`을 호출합니다. 서버의 별도 화면은 없습니다.

승인 결과에는 연결 키가 있습니다. 클라이언트는 해당 키를 조회의 `connectionKey`에 사용합니다. 승인 직후에는 확장이 아직 등록을 받지 않았을 수 있습니다. 팝업에서 소켓 상태를 확인합니다.

| 확인할 경우 | 기대 결과 |
| --- | --- |
| 유효한 코드를 제출합니다. | 연결 키를 한 번 받습니다. |
| 코드가 만료됐거나 이미 사용했습니다. | 연결 키를 받지 못합니다. |
