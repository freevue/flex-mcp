# 팝업 상태 화면

[팝업 계획](../features/extension-ui-plan.md) · [연결 상태 행](../components/connection-rows.md) · [대시보드](work-summary.md)

MCP 소켓이 열려 있으면 상태 화면을 표시합니다. MCP와 Flex 상태는 따로 표시합니다. MCP가 끊기면 연결 화면으로 돌아갑니다.

`코드 확인`은 두 연결이 모두 활성일 때만 우측 상단에 표시합니다. 버튼을 누르면 [추가 연결 코드](../features/browser-pairing.md#연결된-확장에-에이전트-추가)를 복사하고 바로 아래에 툴팁을 표시합니다. 근무 요약의 위치는 그대로입니다. 코드가 승인되거나 만료되면 툴팁을 지웁니다.

Flex 조회를 완료하지 못하면 근무 수치를 숨깁니다. 이때 등록한 계정의 Flex 탭을 연 뒤 `다시 확인`을 누릅니다. 합성 모드에서는 화면에 합성 표시를 넣습니다. 합성 상태는 실제 Flex 로그인을 뜻하지 않습니다.

| 확인할 경우                                                                                   | 기대 결과                                                              |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| MCP만 연결합니다.                                                                             | 두 상태를 표시합니다. 근무 수치는 숨깁니다.                            |
| 같은 프로필에서 Flex 탭을 두 개 엽니다. 최근에 사용한 탭이 등록한 계정으로 로그인돼 있습니다. | MCP와 Flex를 각각 `연결됨`으로 표시합니다. 근무 요약을 표시합니다.     |
| MCP와 Flex가 모두 활성일 때 `코드 확인`을 누릅니다.                                           | 코드를 복사하고 툴팁에 표시합니다. 기존 연결과 근무 요약을 유지합니다. |
| 합성 모드에서 두 상태를 활성화합니다.                                                         | 합성 표시와 근무 요약을 표시합니다.                                    |
| 기존 소켓을 닫습니다.                                                                         | 상태 화면을 닫고 코드 발급을 표시합니다.                               |
