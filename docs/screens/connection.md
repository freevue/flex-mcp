# 팝업 연결 화면

[팝업 계획](../features/extension-ui-plan.md) · [승인 계약](../features/browser-pairing.md)

등록 없는 Chrome에서 처음 팝업을 열면 확장이 등록을 요청합니다. 개인 설치본에서는 같은 프로필의 Flex 계정을 먼저 확인합니다. 발급이 끝나면 승인 코드 영역만 표시합니다. 서버 주소는 확장을 빌드할 때 정합니다.

사용자는 [승인 코드](../components/approval-code.md)를 복사해 MCP 클라이언트에 전달합니다. 소켓이 연결되면 상태 화면으로 이동합니다. 기존 등록이 있으면 자동으로 교체하지 않습니다. 연결이 끊기면 재연결할 수 있습니다.

`renderUnavailablePopup(snapshot)`은 연결 전과 오류 화면을 만듭니다. `snapshot`은 `disconnected` 또는 `error` 상태입니다. 함수는 화면 요소 목록을 반환합니다.

| 확인할 경우                          | 기대 결과                                                                                |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| 등록 없는 Chrome에서 팝업을 엽니다.  | 버튼을 먼저 누르지 않아도 승인 코드 영역을 표시합니다. 연결 상태와 근무 요약은 숨깁니다. |
| 코드를 발급한 뒤 팝업을 다시 엽니다. | 유효한 코드를 다시 표시합니다.                                                           |
| 소켓을 연결합니다.                   | 상태 화면으로 이동합니다.                                                                |
