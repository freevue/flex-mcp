# 팝업 연결 화면

[팝업 계획](../features/extension-ui-plan.md) · [승인 계약](../features/browser-pairing.md)

MCP 소켓이 닫혀 있으면 연결 화면을 표시합니다. 사용자가 코드 발급을 누르면 확장이 서버에 등록을 요청합니다. 서버 주소는 확장을 빌드할 때 정합니다.

요청이 있으면 [승인 코드 영역](../components/approval-code.md)을 표시합니다. 기존 등록이 있으면 재연결도 할 수 있습니다. 접속에 실패하면 등록을 지우지 않습니다.

| 확인할 경우 | 기대 결과 |
| --- | --- |
| 등록 없는 Chrome에서 팝업을 엽니다. | 주소 입력 없이 코드 발급을 표시합니다. |
| 코드를 발급한 뒤 팝업을 다시 엽니다. | 유효한 코드를 다시 표시합니다. |
| 소켓을 연결합니다. | 상태 화면으로 이동합니다. |
